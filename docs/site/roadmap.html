ALX Development Roadmap

ALX is built incrementally. Each version adds real, tested features.

Current Version

ALX 0.1.0 — Foundation Complete

  • .NET 8 solution with CLI
  • Lexer, Parser, AST, Interpreter
  • Types: String, Integer, Float, Boolean, Null
  • Variables & reassignment
  • Arithmetic, comparisons, logical operators
  • print() statement
  • if / else / else if
  • while loops
  • Functions with parameters & return values
  • Diagnostics system with error codes
  • 103 automated tests

ALX 0.2.0 — Enhanced Control Flow Complete

  • For loops with ranges: for i in 1..10 { }
  • Range expressions: 1..10
  • Break statement
  • Continue statement
  • String interpolation: "Hello, {name}!"
  • Documentation website
  • 121 automated tests

ALX 0.3.0 — Functions Improvements Complete

  • Closures
  • Higher-order functions
  • Lambda expressions
  • afun keyword

ALX 0.4.0 — Collections Complete

  • Arrays: [1, 2, 3] with push/pop/contains/indexOf/join/reverse
  • Maps: {name: "Hero"} with keys/values/containsKey/get
  • Member & index assignment
  • VS Code syntax highlighting

ALX 0.5.0 — Objects Complete

  • Classes with methods and properties
  • Constructors with this keyword
  • Inheritance with extends and super

ALX 0.6.0 — Modules Current

  • Import system: import moduleName
  • Import with alias: import math as m
  • Module loading from file system

Future Milestones

ALX 0.7.0 — Game Runtime Foundation

  • Vectors (Vector2, Vector3)
  • Math library
  • Time & input
  • Entity/Component architecture

ALX 0.8.0 — Tooling

  • Language Server Protocol (LSP)
  • VS Code extension
  • Formatter & linter
  • Debugger

ALX 0.9.0 — Bytecode VM

  • Bytecode compiler
  • ALX Virtual Machine
  • Performance optimization

ALX 1.0.0 — Stable Release

  • Stable syntax
  • Stable runtime
  • Standard library
  • Complete tooling
  • Full documentation

Long-Term Vision

ALX is the foundation for the Alexion Engine — a native game development environment.
