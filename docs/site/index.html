Your First ALX Program

Write a file called hello.alx:

// Hello World in ALX
print("Hello, ALEXION!")

Run it:

alx hello.alx

Output:

Hello, ALEXION!

Language Features

// Variables & Types
name = "ALX"
version = 2
health = 100
alive = true

// String interpolation
print("Welcome to {name} {version}!")

// For loops with ranges
for i in 1..10 {
    print(i)
}

// Functions
function factorial(n) {
    if n <= 1 {
        return 1
    }
    return n * factorial(n - 1)
}

print(factorial(5))  // 120
