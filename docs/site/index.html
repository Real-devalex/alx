Your First ALX Program

Write a file called hello.alx:

// Hello World in ALX
print("Hello, ALEXION!")

Run it:

alx hello.alx

Output:

Hello, ALEXION!

Language Features

// Variables & Types
name = "ALX"
version = 4
health = 100
alive = true

// String interpolation
print("Welcome to {name} {version}!")

// Arrays
numbers = [1, 2, 3, 4, 5]
print(numbers.length)    // 5
numbers.push(6)

// Maps
player = {
    name: "Hero",
    health: 100
}
print(player.name)       // Hero

// For loops with ranges
for i in 1..10 {
    print(i)
}

// Functions (use afun or function)
afun factorial(n) {
    if n <= 1 { return 1 }
    return n * factorial(n - 1)
}

print(factorial(5))  // 120

// User input
name = input("What is your name? ")
print("Hello, {name}!")

VS Code Extension

Get syntax highlighting, file icons, and a play button in VS Code:

# Install the extension from the repo
code --install-extension vscode-extension/

# Or copy the extension files to your VS Code extensions folder
# Then restart VS Code

Open any .alx file and click the ▶ play button or press Ctrl+Alt+R to run it.
