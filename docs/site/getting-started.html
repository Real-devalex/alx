Getting Started with ALX

Get up and running with ALX in under 5 minutes.

Prerequisites

ALX requires the .NET 8 SDK or later.

# Check your .NET version
dotnet --version

If you don't have .NET installed, download it from dotnet.microsoft.com.

Installation

Option 1: Quick Install (Recommended)

Download the latest release and run the installer:

# Download from GitHub Releases
# https://github.com/Real-devalex/alx/releases/latest

# Extract and run install.ps1
.\install.ps1

# Restart your terminal, then:
alx version

Option 2: Build from Source

# Clone the repository
git clone https://github.com/Real-devalex/alx.git
cd alx

# Build
dotnet build ALX.sln

# Run your first program
dotnet run --project src/ALX.CLI -- examples/hello.alx

Updating ALX

When a new version is released, update with one command:

alx update

This downloads and installs the latest version automatically. No need to reconfigure PATH or settings.

VS Code Extension

ALX comes with a VS Code extension that provides:

  • Syntax highlighting for all ALX keywords
  • File icons — purple ALX icon in the explorer
  • Play button — click ▶ or press Ctrl+Alt+R to run
  • Output panel — shows program output with timing

Install the Extension

# From the ALX repo directory
code --install-extension vscode-extension/

# Restart VS Code
# Open any .alx file — you'll see the play button!

Alternatively, copy the vscode-extension/ folder contents to your VS Code extensions directory at %USERPROFILE%\.vscode\extensions\alx-language-support-0.4.0\.

Your First ALX Program

Create a file called hello.alx:

// hello.alx — My first ALX program
print("Hello, ALEXION!")

Run it from your terminal:

alx hello.alx

Or in VS Code: open the file and click the ▶ play button.

Output:

Hello, ALEXION!

Interactive Programs

ALX supports user input with the input() function:

// calculator.alx
print("=== ALX Calculator ===")

a = input("Enter first number: ")
b = input("Enter second number: ")

print("You entered: {a} and {b}")

input() reads a line from the user. Pass a string argument to show a prompt:

name = input()                    // no prompt
name = input("Enter name: ")      // with prompt

Updating ALX

ALX can update itself from GitHub:

# Check for and install updates
alx update

# Shows current vs latest version, downloads and installs automatically

You can also re-run the installer for a manual upgrade:

.\install.ps1

The installer detects if ALX is already installed and upgrades in-place.

CLI Commands

CommandDescription
alx <file.alx>Run an ALX source file
alx run <file.alx>Run an ALX source file (explicit)

alx versionShow ALX version
alx helpShow help message
