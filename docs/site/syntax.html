Loops

While Loop

x = 5
while x > 0 {
    x = x - 1
    print(x)
}

For Loop with Range

// Basic for loop
for i in 1..5 {
    print(i)  // 1, 2, 3, 4
}

// Sum with for loop
total = 0
for i in 1..100 {
    total = total + i
}

Break & Continue

// Break — exit the loop
for i in 1..10 {
    if i == 5 {
        break
    }
    print(i)  // 1, 2, 3, 4
}

// Continue — skip to next iteration
for i in 1..6 {
    if i % 2 == 0 {
        continue
    }
    print(i)  // 1, 3, 5
}

Functions

// Declaration
function greet(name) {
    print("Hello, {name}!")
}

// Call
greet("World")

// Return values
function add(a, b) {
    return a + b
}

result = add(10, 20)

// Recursion
function factorial(n) {
    if n <= 1 {
        return 1
    }
    return n * factorial(n - 1)
}

print(factorial(5))  // 120

String Interpolation

Embed expressions inside strings using {expression}:

name = "Daniel"
version = 2

print("Hello, {name}!")           // Hello, Daniel!
print("ALX {version} - {name}")   // ALX 2 - Daniel
print("Sum: {10 + 5}")           // Sum: 15

Ranges

Range expressions represent a sequence of integers:

// Range syntax: start..end (end is exclusive)
for i in 0..5 {
    print(i)  // 0, 1, 2, 3, 4
}

// Store ranges in variables
r = 1..10
print(r)  // 1..10
