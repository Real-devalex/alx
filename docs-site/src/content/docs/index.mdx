## Make something move in minutes

```alx title="game.alx"
hero = new Entity("Hero", 0, 0)
hero.velocity = new Vec2(4, 3)

for tick in 1..3 {
    hero.update(1)
    print("tick {tick}: hero is at {hero.position.toString()}")
}
```

```text title="Output"
tick 1: hero is at (4, 3)
tick 2: hero is at (8, 6)
tick 3: hero is at (12, 9)
```

## Your first five minutes

<Steps>

1. **Install ALX.** Follow the [install guide](/alx/learn/install/).

2. **Write your first program.** One line: `print("Hello, ALEXION!")`.

3. **Run it.** `alx run hello.alx`

4. **Learn the basics.** Variables, decisions, loops, functions and classes, each in a few minutes.

5. **Build a tiny game loop.** Use `Vec2` and `Entity`.

</Steps>
