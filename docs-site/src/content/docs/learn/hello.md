Create a file called `hello.alx` and type:

```alx
print("Hello, ALEXION!")
```

Run it:

```bash
alx run hello.alx
```

You will see:

```text
Hello, ALEXION!
```

## What happened

- `print(...)` shows something on the screen.
- Text goes inside quotes. Programmers call that a **string**.
- Every line is an instruction. ALX runs them from top to bottom.

## Comments

Anything after `//` is ignored. Use it to leave notes for yourself.

```alx
// This is a note. ALX skips it.
print("Hi") // This also works at the end of a line
```

:::tip[Try it]
Change the message, then run it again. Print two lines.
:::
