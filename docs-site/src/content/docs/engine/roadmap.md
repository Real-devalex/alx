| Version | Theme | Status |
| --- | --- | --- |
| 0.1 to 0.6 | Foundation, control flow, functions, collections, objects, modules | Done |
| 0.7 | **Game runtime**: math, random, time, `Vec2`, `Entity`, CI | Done |
| 0.8 | **Language polish**: friendly errors, richer strings and arrays, `try` and `catch`, type hints, timers, `save` and `load`, one-click Windows zip | Next |
| 0.9 | **Engine alpha**: window, sprites, input, collision, sound, animation, tile maps, scenes, UI, hot reload. First game: Pong | Planned |
| 0.10 | Templates (platformer, top-down, shooter) and the Language Server. Game: Coin Run | Planned |
| 0.11 | Small top-down roleplay prototype | Planned |
| 0.12+ | ALX Studio editor, browser playground, bytecode VM, multiplayer rooms, server mode, 3D | Later |

Read the full reasoning in the [master plan](/alx/engine/plan/).
