| Version | Theme | Status |
| --- | --- | --- |
| 0.1 to 0.6 | Foundation, control flow, functions, collections, objects, modules | Done |
| 0.7 | **Game runtime**: math, random, time, `Vec2`, `Entity`, CI, docs, VS Code extension | Done |
| 0.8 | **Language polish**: ranges include the end, friendly errors, richer strings and arrays, `try` and `catch`, type hints, timers, `save` and `load`, one-click Windows zip | Next |
| 0.9 | **Engine alpha (2D)**: window, sprites, input, collision, sound, animation, tile maps, scenes, UI, hot reload. First game: Pong | Planned |
| 0.10 | **ALX Studio alpha**: scene view, inspector, Play button, live editing. Language Server. Game: Coin Run | Planned |
| 0.11 | Studio and templates: prefabs, tile map and animation editors | Planned |
| 0.12 | **3D foundations**: `Vec3`, cameras, glTF models, lighting, 3D physics | Planned |
| 0.13 | Small roleplay prototype | Planned |
| 0.14+ | Browser playground, bytecode VM, multiplayer rooms, server mode, Android and web export, visual scripting | Later |

Read the full reasoning in the [master plan](/alx/engine/plan/).
