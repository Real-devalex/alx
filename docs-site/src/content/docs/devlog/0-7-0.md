ALX 0.7.0 is the first release built with a game engine in mind.

## What is new

Games need a few things all the time: square roots, random numbers, a way to say "a point halfway between two places", and a thing that has a position and moves. They are all built in now.

```alx
hero = new Entity("Hero", 0, 0)
hero.velocity = new Vec2(4, 3)
hero.update(1)
print(hero.position.toString())   // (4, 3)
```

## How it was built

`Vec2` and `Entity` are written in ALX itself. They load before your program starts. That means the language is already strong enough to describe its own game objects.

Because this PC has no .NET installed, every change is built and tested by GitHub. Each push builds ALX, runs the tests and runs every example. Nothing reaches the main branch unless it is green.

## What is next

0.8.0 is about being kind to beginners: friendly error messages, richer text and array tools, `try` and `catch`, timers, and saving a game. After that, the engine: a real window, sprites and your first game, Pong.
